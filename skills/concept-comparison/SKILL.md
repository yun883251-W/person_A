# 概念比较

## 技能用途

用于回答“两个或多个概念有什么区别、在什么条件下选择哪个”一类问题。比较维度应由用户的使用场景和资料内容决定，避免只分别解释概念而没有形成可用的比较结论。

这是 Person A 应用内部的技能说明，不是已安装的 Codex 技能。

## 状态

待开发。`skill_loader` 与 Agent 尚未接入；仅创建本文件不会使技能自动加载、触发或执行。
