# 代码解读

## 技能用途

用于解读用户提供的 Python、LangChain、RAG、Agent 或 LangGraph 相关代码。以理解代码为目标，解释输入输出、执行顺序和关键调用，并区分可直接从代码观察到的事实与需要文档支持的框架行为。

这是 Person A 应用内部的技能说明，不是已安装的 Codex 技能。

## 状态

待开发。`skill_loader` 与 Agent 尚未接入；仅创建本文件不会使技能自动加载、触发或执行。
