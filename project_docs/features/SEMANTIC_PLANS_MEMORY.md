# 语义补充、自然语言规划与长对话摘要

这三项能力共同解决规则系统中的长尾表达，同时维持工具授权和调用预算边界。

## 受限语义补充

规则无法识别 B 站请求措辞时，系统可调用一次分类模型，输出严格的 `kind/query/mode/limit` JSON。`query` 必须逐字出现在当前输入中；`mode` 与数量必须符合原文要求。结构错误、额外字段或主题不一致都会退回澄清。

知识追问中的代词也可做受限改写。改写只能使用最近历史中明确出现的主题，并保留原问题的比较维度和限制条件。

## 自然语言多任务

显式编号、连接词或语义分类可触发最多 3 步的计划。规划器保留每个原始从句，建立前向依赖，并为实际执行预留模型与工具预算。知识步骤和 MCP 步骤使用各自的权限边界，不能相互继承工具授权。

## 长对话摘要

当早期知识问答移出最近历史窗口时，系统在提交新轮次后生成结构化主题摘要。摘要只压缩已提交的用户问题和回答，不包含工具内部消息、异常详情或模型推理。完整原始轮次仍保存在 SQLite，可通过历史接口查看。

摘要与可编辑记忆分开：摘要反映历史内容，记忆反映用户主动维护的当前背景。清空记忆会设置遗忘边界，旧摘要不会再次把已清除内容带回上下文。

三类语义调用都计入整轮模型预算，并为最终回答或工具执行预留最低调用次数。
