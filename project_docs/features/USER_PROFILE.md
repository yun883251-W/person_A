# 本地学习画像

学习画像用于稳定保存跨会话的回答偏好和学习背景。当前部署模型是本机单用户，固定画像 ID 为 `local`。

## 字段

- Python 基础
- 学习目标
- 回答方式
- 开发环境
- 学习进度
- 语言偏好

每个字段保存值、来源和更新时间。保存使用 revision 做乐观并发控制，多个页面同时编辑时拒绝旧版本覆盖。

## 候选提取

用户可提交一段自我描述，让模型提取结构化候选。提取结果不会自动写入画像：页面先展示候选，用户逐项采用并点击保存。模型不得把临时请求、系统猜测或对话中隐含的信息当作长期事实。

画像只作为独立背景注入回答上下文，不参与知识引用，也不改变工具授权。用户可编辑或清空任意字段。

API 位于 `/profile` 及其候选提取子资源。公开响应不包含模型原始提示、内部错误或敏感配置。
