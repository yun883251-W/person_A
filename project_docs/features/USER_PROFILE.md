# 用户画像与候选提取

当前实现说明；已开发，尚未运行测试或真实模型调用。

侧栏“我的学习偏好”支持 Python 基础、学习目标、回答方式、开发环境、学习进度和语言偏好。
固定本机用户 `local` 跨会话共享，尚无多用户登录隔离。默认保存到
`data/sessions/chat.profile.db`，文件名由 `SESSION_DB_PATH` 派生。

知识问答、计划中的知识步骤及普通聊天可读取画像，MCP 路由不携带画像。
开发环境与进度按相关问题关键词选择，其余字段作为可选背景；不修改检索问题。
执行详情显示注入状态和字段数，不展示画像正文。读取失败时跳过画像。

`GET /profile` 读取；`POST /profile` 用 `{enabled, fields, expected_revision}` 替换；
`POST /profile/clear` 用 `{expected_revision}` 清空并关闭。
关闭只停止注入；清空删除画像与字段元信息，不删除聊天或摘要。
需要去除会话中的旧偏好时，参见 [记忆纠错与遗忘](CHAT_MEMORY.md)。
正在生成的回答可能已读取旧快照。浏览器不在 localStorage 保存画像。

### 画像字段来源、时间与冲突处理

画像接口保留原来的 `fields`、`revision`，新增 `field_metadata`。
每个非空字段记录 `source` 和 `updated_at`：新填、修改或明确重新确认的字段
为 `manual`；旧数据没有逐字段时间时为 `legacy_manual`、时间为空，不把整份画像
更新时间误当成字段时间。原有客户端无需传新字段。

`POST /profile` 可选 `confirmed_fields`（最多六个已填写字段名）用来确认旧值
仍有效。未改变也未确认的字段保持原时间，仅切换开关不会刷新字段时间。
字段删除及清空画像会同步移除元信息。首次保存时在独立画像数据库中创建
`profile_field_metadata`，读旧库不执行迁移，元信息与画像在同一事务提交。

页面逐字段显示来源与时间，并提供“确认仍有效”（点击后需保存）。
学习进度超过 30 天、其他字段超过 90 天未确认时提醒核对；未知时间也提醒。
这些是界面提醒，不自动判定失效、删除或停用字段。学习进度和基础水平始终视为自述。

画像正文现在是独立的 HumanMessage 数据块，带字段来源、时间和画像版本。
系统消息只保存固定使用规则；画像不授予工具权限，不作为知识引用，不回存为新一轮
用户消息。预算仍优先裁掉画像，使用既有当前消息起点保存逻辑。
当前请求和本轮明确更正优先；可确认更新的用户更正优先于旧画像；
画像优先于旧摘要。无法判断冲突先后时要求澄清，不把历史窗口位置当作时间证据。
该冲突处理是提示词约束，尚不是逐字段自动合并算法。

仍使用本机共享 `local` 用户；尚未增加登录隔离、后台自动收集画像、
逐条跨会话遗忘或模型驱动的字段选择。删除画像后，若旧偏好仍在聊天记忆中，
还需通过对应会话的“纠正或清空会话记忆”处理。

本次未运行测试、服务或实际画像库迁移。待联调：旧库显示未知字段时间、
只改一项时其他时间不变、确认后保存、清空后元信息同步删除、并发保存冲突、
聊天与知识问答的独立画像注入及裁剪后会话保存。
### 从用户描述生成画像候选

“我的学习偏好 → 从我的描述提取候选偏好”支持粘贴自己的对话描述，
例如“我是 Python 初学者，平时喜欢先看例子再看原理。我使用 Windows”。
点击提取后，每个候选展示字段、候选值、当前编辑值和依据原话。
可逐项采用到表单或忽略，最后仍需点击保存；采用不会直接写数据库，
覆盖非空编辑值前会提示。模型候选被用户确认保存后归为手动确认来源。

`POST /profile/propose` 接收 `text`（1—3000 字符）和 `expected_revision`。
只分析显式提供的文本，不读取全部聊天、不注入现有画像正文，不自动收集或定时提取。
调用当前配置的聊天模型一次，无工具、无传输重试，与业务工作线程串行执行。
返回 `candidates`、`revision`、`model_calls`，无候选是正常结果；
输入清理后为空时不调用模型。候选及输入不在服务器新增持久化记录。

程序校验字段白名单、长度、重复字段、严格 JSON 字段以及原文对应关系：
候选值必须包含在引用原话中，原话必须是清理后输入的连续片段。
模型被要求忽略第三方引述、假设、临时请求、敏感信息和无法确定的冲突。
原文匹配只能验证出处，不能证明模型对第一人称或长期性的理解正确，因此仍需人工核对。
提取前后核对画像版本，过期返回 409；无效输出返回 502；模型不可用返回 503。
保存继续使用既有版本检查。提取失败不清空已编辑字段，也不自动写入或重试。

与问答不同，画像提取是单独操作，`model_calls` 在该接口返回，不计入任何问答 trace。
提取使用现有模型配置：若配置云端模型，提交的描述会发送给该提供方。
当前未加入聊天结束后的自动候选推送、多用户画像隔离或跨会话自动画像合并。
本次只开发，未运行测试或真实模型请求。待联调：明确自述、临时要求、
第三方引述、矛盾描述、模型非法 JSON、提取期间另一窗口保存、逐项采用与最终保存。
