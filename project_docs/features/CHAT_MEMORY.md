# 聊天与记忆

Person_A 支持 `auto`、`knowledge` 和 `chat` 三种回答模式。自动模式先保护工具与待补任务边界，再在知识问答和普通聊天之间分流。

## 会话上下文

- 最近对话按轮次和字符预算进入模型上下文。
- 较早的知识问答压缩为主题化摘要，完整原始历史继续保存在 SQLite。
- 摘要、最近历史、用户维护的会话记忆和学习画像分别注入，来源不会混淆。
- 模型看不到未授权的内部业务状态、工具参数来源或其他会话内容。

## 可编辑记忆

`GET/POST /sessions/{id}/memory` 提供当前会话的背景说明。保存时记录截止轮次；清空后，更早聊天不会再次通过摘要进入后续上下文。原始历史仍用于用户查看和审计。

适合保存当前学习主题、已经确认的结论和回答偏好。界面明确提示不要填写密码或 API Key。

## 持久化语义

单轮回答与其摘要、trace、业务状态在同一事务提交。普通服务错误不进入历史；客户端断连后应先读取历史确认是否已经提交，避免重复请求。

本项目定位为单机个人应用，不提供账号系统或跨设备同步。
