# MBTI MCP

MBTI 能力作为独立 stdio MCP 服务运行，提供题目分页、确定性评分和类型描述。题库与评分代码已内置在 `src/mbti_mcp/`，运行主项目不依赖外部仓库或数据库。

## 工具

- 获取题目：按稳定题库版本返回题目和选项。
- 计算结果：接收完整的 48 道 1—5 分答案，返回四个维度及类型。
- 查询类型描述：按合法的四字母类型返回一般性说明。

宿主只传递用户实际作答；模型不能生成、补齐或修改答案。缺题、题号错位、版本变化、非法分数和重复提交均由程序拒绝。

## 会话体验

在 `person-a chat` 或 Web 会话中输入“开始 MBTI 测试”。支持暂停、继续、退出、重新开始和查看结果。Web 页面使用带题号和测试 ID 的按钮值，历史题目卡无法重复提交到当前状态。

答题快照与问答轮一起保存在 SQLite 的结构化结果中。重启后可继续，清空或删除会话会同步删除答题状态。

## 结果解释

四个维度展示两极累计分值的占比，而非统计置信度。平局采用题库原有的稳定规则并在结果中说明。类型描述用于自我了解，不用于医疗、心理诊断、招聘筛选或推断用户没有表达的特征。

默认 `config/mcp_servers.json` 已启用该服务，安装 `.[api,mcp]` 后由宿主自动管理子进程生命周期。
