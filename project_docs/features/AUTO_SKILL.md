# 自动 Skill 与检索策略

Person_A 提供三种知识问答 Skill：概念讲解、概念比较和代码解读。Skill 可以手动指定，也可以在 `auto` 模式下按问题自动选择。

## 选择流程

1. 读取 Skill 的 ID、名称和描述，不加载正文。
2. 规则能够确定时直接选择，不增加模型调用。
3. `hybrid` 模式下，规则无法确定且预算允许时调用一次分类模型。
4. 无匹配或分类失败时回退普通知识问答。
5. 只有最终选中的 Skill 正文会进入回答上下文。

自动选择仅用于知识路线；问候、闲聊、MBTI 和 MCP 操作不会进入 Skill 选择。复合任务中的每个知识步骤独立选择，工具步骤保持隔离。

## 模式

| 模式 | 行为 |
| --- | --- |
| `off` | 普通知识问答 |
| `manual` | 使用明确指定的 Skill ID |
| `auto` | 规则优先，必要时使用受限语义分类 |

CLI 示例：

```powershell
person-a ask "比较 Chain 和 Agent" --skill-mode auto
person-a ask "解释这段代码" --skill code-explanation
```

## 工具与证据边界

Skill 只能看到为知识问答注册的只读检索工具。加载器会对允许工具取交集，Skill 文件无法自行扩大工具集合。Skill 指令影响回答组织方式，但不是事实证据；最终引用仍必须来自本轮真实检索片段。

不同 Skill 可采用不同检索策略：

- 概念讲解：围绕单一主题检索定义、机制和示例。
- 概念比较：分别覆盖比较对象，再补充共同维度。
- 代码解读：优先检索可见标识符、相关 API 和上下文说明。

检索步骤共享整轮工具预算，结果按 chunk ID 去重，并保留索引版本和来源元数据。

## 可观测性

执行摘要会记录选择模式、决策来源、选中 Skill、检索策略和实际应用阶段。页面只展示公开过程数据，不展示分类模型的内部推理。
